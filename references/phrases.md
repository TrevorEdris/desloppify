## Business jargon (P1) — replace with plain alternative

| Replace | With |
|---|---|
| `navigate the complexities of` | handle |
| `unpack` | explain |
| `lean into` | embrace |
| `landscape` | field |
| `game-changer` | important |
| `double down` | commit |
| `deep dive` | analysis |
| `take a step back` | reconsider |
| `moving forward` | next |
| `circle back` | revisit |
| `on the same page` | aligned |
| `low-hanging fruit` | easy win |
| `think outside the box` | rethink |

## Character normalization (P1) — deterministic

| Replace | With |
|---|---|
| `—` (em dash) | `-` |
| `–` (en dash) | `-` |
| `“` (left curly quote) | `"` |
| `”` (right curly quote) | `"` |
| `‘` (left curly apos) | `'` |
| `’` (right curly apos) | `'` |
| `…` (ellipsis) | `...` |
